1.Ya, saya menggunakan elemen semantik HTML5 dalam merancang struktur website portofolio ini. Pada dokumen HTML yang telah dibuat, saya secara spesifik mengimplementasikan elemen seperti <header>, <nav>, <main>, <section>, dan <footer>. Penggunaan elemen-elemen ini sangat membantu dalam mendefinisikan hierarki dan tujuan dari setiap bagian halaman secara logis, dibandingkan sekadar menumpuk tag <div>. Pendekatan ini membuat kode lebih bersih, mudah dikelola, serta secara fundamental meningkatkan aksesibilitas dan semantik web.

Penyesuaian ke dalam satu kolom linier (1fr) ini memastikan alur membaca tetap berurutan dan natural.

3.Batasan utama dari static web murni adalah ketidakmampuan untuk memperbarui konten secara dinamis dan praktis.
